# LANDELTA 0.12 — delta e historial

- Tamaño independiente del delta con botones y rueda al desbloquear.
- Opción **Fuera de sesión** para activar los overlays después de la carrera; el último delta aparece como **Δ FIN**.
- El delta funciona en vueltas inválidas: mejoras amarillas y pérdidas rojas. Las vueltas inválidas no reemplazan la referencia limpia.
- **Historial → Circuito → Sesión → Exportar PNG** guarda todas las vueltas y sectores en imágenes legibles de hasta 40 vueltas.

Descarga **LANDELTA-Windows-Beta.zip**, extrae y sustituye el ejecutable con LANDELTA cerrado. Se conservan tus ajustes e historial.

Validación: pruebas automatizadas de lógica y APIs simuladas, compilación Windows x64. Falta la prueba en una carrera real de ACC para estas novedades.
